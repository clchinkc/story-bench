# W4 Dataset, Split and Blind-Annotation Contract

This offline infrastructure validates metadata only. It stores no story text, private manuscript, rights decision, human label or provider output. Dataset references require closed fields, explicit rights metadata and a SHA-256 content digest. Group identity precedes variants and cannot cross splits. Holdout requires a seal and exact release token. Annotation packets require blank label/confidence fields and reject arm, treatment, model, provider, prediction, reward, outcome and split fields. Rights, corpus inclusion, rubric semantics and all human judgments remain user-owned decisions.
