# Creative-writing assessment dimensions

This is a vocabulary reference, not a model ranking or scoring protocol. The 2025 free-tier impressions and unverified 1–10 rankings formerly here have been retired; they lacked reproducible model snapshots, paired tasks and human calibration.

Useful dimensions include narrative causality, character knowledge/belief, emotional plausibility, voice, dialogue, context retention and response to author intent. Their applicability depends on the actual task. More detail, longer context windows, particular sentence lengths or a prescribed emotional arc do not imply better writing. “Human-like” phrasing is not an authorship detector.

Model capability, provider restrictions, cost/latency and interface limits are separate operational facts, verified for a frozen version when used. They are not a universal literary ranking.

The executable specification is [experiment-contract.md](experiment-contract.md), especially artifact/critic/generation assessment and statistical calibration. Use genuine blinded author judgments, evidence-bound criteria and pairwise ties/cannot-assess. Do not reinstate scalar impressions as ground truth.
